# Client Logos

This folder contains client logos for the website. 

## Adding New Logos

1. Add your logo image files to this folder (supports PNG, JPG, SVG)
2. Update the client data in `src/data/clients.ts` with the new logo path
3. Logo path format: `/clients/your-logo-name.png`

## Recommended Logo Specifications

- Format: PNG with transparent background (preferred) or JPG
- Size: Minimum 200x100px for best quality
- Aspect Ratio: Maintain company branding proportions
- File Size: Keep under 500KB for optimal loading
